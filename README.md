# willOS — demo playlist

Demo playlist and programme guide used to test the willOS app for LG webOS TV.

- Playlist (M3U): https://willsearch.github.io/willos-demo/lista.m3u
- Guide (XMLTV): https://willsearch.github.io/willos-demo/guia.xml

Content: *Big Buck Bunny*, *Elephants Dream*, *Sintel* and *Tears of Steel* © Blender Foundation,
Creative Commons Attribution (www.blender.org). Other streams are public test signals from
Apple, Unified Streaming, Mux, JW Player and test-videos.co.uk. The programme guide is
a fictional demo schedule.

Posters (`posters/`) are cropped from the films' official posters (Big Buck Bunny, Sintel — via Wikimedia Commons)
and from frames of the films (Elephants Dream, Tears of Steel). All © Blender Foundation, CC BY.
Channel logos (`logos/`) are simple placeholders made for this demo.
